## 🔗 Live Preview
Open `index.html` in your browser to view the site.

- `index.html` – Main portfolio page (Home, About, Skills, Projects, Education, Contact)
- `python.html` – Detailed Python skills page

- `script.js` – Smooth scrolling, dynamic footer year, and interactivity
